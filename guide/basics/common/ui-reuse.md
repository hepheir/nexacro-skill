# 공통 화면·컴포넌트·템플릿은 어떻게 다른가요?

[매뉴얼 목차](../../README.md)

**재사용할 대상이 디자인인지, 실행되는 기능인지, 새 화면의 시작 틀인지에 따라 방식이 다릅니다.**

## 목적에 맞는 방식

| 반복되는 내용 | 구성 방법 |
| --- | --- |
| 버튼 색상·폰트 | Theme/XCSS와 cssclass |
| 검색 조건처럼 묶인 영역 | 별도 Form을 Div 등에 포함 |
| 사원 선택처럼 독립된 창 | 팝업 Form과 공통 호출 함수 |
| 회사 전용 입력 컨트롤 | 사용자 컴포넌트·모듈 |
| 새 업무 화면의 기본 틀 | Form Template·Code Snippet |

템플릿과 Snippet은 생성할 때 내용을 복사합니다. 원본 템플릿을 고쳐도 이미 만든 모든 화면이 함께 바뀌지는 않습니다. 공유 Form이나 공통 함수는 공유 코드를 바꾸면 여러 사용처에 영향을 줍니다.

## 공통 Form을 포함하는 예

Div의 `url`에 `Common::SearchArea.xfdl`처럼 등록된 Form을 지정할 수 있습니다. 포함된 Form의 내부 경로는 `divSearch.form...` 형태입니다. 이름과 경로는 설명용입니다.

부모 화면이 내부 Edit를 일일이 고치기보다 공통 Form이 제공하는 함수와 입력·결과 규약을 확인합니다. URL을 지정한 직후에는 로딩·초기화가 끝났다고 가정하지 않습니다.

## 회사 모듈을 사용할 때

TypeDefinition의 객체·모듈 등록과 라이브러리 버전, 배포 파일이 맞아야 합니다. 기존 화면과 사내 사용 가이드를 기준으로 설정합니다. 팝업 역시 회사 공통 함수의 인자와 결과 callback 규칙을 따릅니다.
