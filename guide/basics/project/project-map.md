# 회사 프로젝트를 빠르게 파악하려면요?

[매뉴얼 목차](../../README.md)

**조회·저장이 동작하는 비슷한 화면 하나를 골라 끝까지 추적합니다.** 전체 프로젝트의 모든 파일을 먼저 이해하려고 할 필요는 없습니다.

```text
버튼 이벤트 → 공통 함수 → 요청 URL → Controller
    → Service / SQL → 응답 Dataset → Grid와 상세
```

## 화면 쪽에서 적어 둘 것

| 항목 | 확인 위치 |
| --- | --- |
| Studio·엔진 버전 | 개발환경 안내·프로젝트 라이브러리 |
| 생성 경로·실행 URL | Studio Options·Run Configuration |
| 공통 초기화·통신 함수 | include 파일과 호출부 |
| 스타일·공통 화면 | Theme/XCSS·기준 화면 |
| Dataset 계약 | 컬럼·바인딩·input/output 매핑 |

조회 버튼에서 시작해 URL과 매핑을 찾고, 응답이 어느 Dataset에 들어가는지 확인합니다. 목록과 상세가 같은 데이터를 보는지도 따라갑니다.

## 서버 쪽에서 이어 보기

요청 URL로 Controller를 찾고 Service와 SQL을 따라갑니다. 입력 Dataset을 어떤 Java 데이터로 받는지, 결과를 어떤 이름으로 응답하는지 확인합니다. 저장이라면 삭제 행 처리와 커밋·롤백 범위도 확인합니다.

로그인 정보나 공통 코드가 전역 Dataset에 있다면 초기화·갱신 주체를 기록합니다. 한 화면의 임시 편집값으로 공유 데이터를 덮어쓰지 않도록 역할을 구분하세요.

## 기록은 짧게 남깁니다

“조회 함수 / 호출 URL / 수신 Dataset / 공통 처리 / 막힌 지점” 정도면 시작하기 충분합니다. 기밀 주소나 소스를 외부에 공유할 필요 없이 사내에서 참고할 메모로 사용합니다.
