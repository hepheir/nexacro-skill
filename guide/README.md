# 넥사크로 스튜디오, 첫 화면부터 사원관리까지

> **목표:** 목록에서 사원을 선택하고, 상세 정보를 수정하는 화면을 내 손으로 만든다.

투비소프트 에듀의 **Nexacro Platform 17.1 기본 강의 6편**을 바탕으로 만든 자습 가이드입니다. JavaScript의 변수·함수 정도를 알고 있으면 시작할 수 있습니다.

## 이렇게 공부하세요

**핵심 읽기 → 필요한 영상 구간 보기 → 직접 실습 → 완료 체크** 순서로 진행하세요. 한 번에 전부 외울 필요는 없습니다. 막히면 각 장의 ‘막혔다면’부터 확인하세요.

| 순서 | 이번에 만들 것 | 학습 문서 |
| --- | --- | --- |
| 1 | 실습할 프로젝트 | [개발환경과 프로젝트](01-start.md) |
| 2 | 클릭하면 반응하는 버튼 | [첫 화면과 이벤트](02-hello.md) |
| 3 | 사원관리 화면의 뼈대 | [컴포넌트와 배치](03-components.md) |
| 4 | 함께 바뀌는 목록·상세 화면 | [Dataset과 바인딩](04-binding.md) |
| 5 | 부서명과 합계가 보이는 표 | [Grid 편집](05-grid.md) |
| 6 | 추가·삭제와 서버 조회·저장 | [데이터 통신](06-transaction.md) |
| 마무리 | 설명 없이 다시 만드는 화면 | [최종 미션과 문제 해결](07-mission.md) |

추천 분량은 하루 1~2장입니다. 영상 전체 길이보다 **직접 동작을 확인했는지**를 기준으로 넘어가세요.

## 준비물

- [ ] Nexacro Studio 17.1을 사용할 수 있는 개발 PC와 실행 환경
- [ ] 교육용 `EduProject17.1` 샘플 프로젝트 또는 별도 연습 프로젝트
- [ ] 원본과 구분되는 실습용 복사본
- [ ] 6장 서버 실습을 위한 개발 서버 주소와 요청·응답 Dataset 정의

교육자료 링크는 [2강 원문](<../기본02. 개발환경 설정과 Hello.md>) 상단에 있습니다. 링크의 현재 제공 여부는 확인하지 않았습니다. 자료를 구할 수 없다면 사내 교육 담당자에게 샘플을 요청하거나, 1장의 새 프로젝트 경로로 시작하세요. **1~5장과 6장의 행 추가·삭제는 서버 없이 진행할 수 있습니다.**

## 완성할 화면

```text
[조회] [추가] [삭제] [저장]
┌─────────────────────┬───────────────────────┐
│ 사원 목록 Grid      │ 이름   [김하나      ] │
│ 사번 / 이름 / 부서  │ 사번   [E001        ] │
│ E001 김하나 개발팀  │ 부서   [개발팀    ▼] │
│ E002 이두리 기획팀  │ 급여   [3,000,000   ] │
├─────────────────────┤                       │
│ 총 2건 / 급여 합계  │ 선택한 사원의 상세    │
└─────────────────────┴───────────────────────┘
```

화면은 데이터를 보여주고, **Dataset은 데이터를 보관합니다.** 목록과 상세를 같은 Dataset에 연결하는 것이 이번 과정의 중심입니다.

## 자료 기준

이 가이드는 저장소 `youtube/`의 강의 자막을 재구성했습니다. 영상 전체를 새로 시청해 검증한 문서는 아닙니다. 영상 이동 시간은 원문 설명란의 잘못된 목차 대신 **자막에 있는 시점**을 기준으로 골랐습니다.

원본의 실습 흐름을 줄여 별도의 연습용 이름·데이터·코드를 사용합니다. 실제 샘플의 ID가 다르면 해당 ID에 맞추세요. 영상 속 브라우저·설치·라이선스 안내는 녹화 당시 설명이므로 실습 환경은 사내 안내를 따르세요.
